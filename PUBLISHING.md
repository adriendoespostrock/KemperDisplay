# Publishing checklist

- [ ] Add the real Xcode project (`.xcodeproj`) to the repository
- [ ] Add screenshots to `Screenshots/`
- [ ] Choose an open-source license
- [ ] Set the app version and build number
- [ ] Test a Release build on another Mac
- [ ] Sign with Developer ID for public distribution
- [ ] Enable Hardened Runtime
- [ ] Notarize the public build with Apple
- [ ] Create a GitHub Release and attach the signed/notarized `.zip` or `.dmg`
